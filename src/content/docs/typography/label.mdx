## Overview

`Label` renders a `<label>` element using the fixed font-size scale (`--fsf--*`) rather than the responsive scale used by `Text` and `Heading`. This keeps form layouts stable across breakpoints — form field labels must not reflow or shift size as the viewport changes.

Defaults: `size="sm"`, `weight="medium"`.

---

## Usage

### Basic

```astro
<Label for="email">Email address</Label>
```

---

### Required indicator

`required` appends a visual `*` that is `aria-hidden`. Always also set `required` on the control itself for native validation and ARIA semantics — the indicator is for sighted users only.

```astro
<Label for="password" required>Password</Label>
```

---

### Custom typography

```astro
<Label for="bio" size="xs" weight="normal" color="secondary">
  Short bio (optional)
</Label>
```

---

### Icon

```astro
<Label for="email" icon="mail">Email address</Label>
<Label for="secret" icon="lock" required>Password</Label>
```

---

### Inside a Field

```astro
<Field id="email">
  <Label slot="label" for="email" required>Email</Label>
  <Input id="email" name="email" required />
</Field>
```

---

## Props API

| Prop | Type | Default | Description |
|---|---|---|---|
| `for` | `string` | `undefined` | ID of the associated form control. |
| `required` | `boolean` | `false` | Renders a visual `aria-hidden` asterisk after the label text. |
| `size` | `"2xs" \| "xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"sm"` | Fixed-scale font size (does not use responsive clamp). |
| `weight` | `"normal" \| "medium" \| "semibold"` | `"medium"` | Font weight. `bold` and `black` are excluded. |
| `icon` | `SvgName` | `undefined` | Leading icon rendered before the slot. |

Inherits remaining `TypographyProps` (`color`, `align`, `leading`, `tracking`, `fam`, etc.) and `BaseComponentProps`.

---

## Accessibility

- `required` on Label is **visual only** — it renders an `aria-hidden` `*`. Set `required` (or `aria-required="true"`) on the corresponding `<Input>` or `<Select>` for screen reader announcement.
- The `for` prop creates a native association between label and control. Clicking the label focuses the control and is especially important on mobile.
- Avoid placing interactive elements (buttons, links) inside a Label — this creates confusing focus and click behavior.
