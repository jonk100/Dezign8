## Overview

`Kbd` renders a `<kbd>` element with monospace font, a subtle border, slightly thicker bottom edge (to suggest a physical key), and a muted background. Use it to represent keyboard shortcuts, key names, or input sequences.

Defaults: `size="xs"`, `fam="mono"`.

---

## Usage

### Single key

```astro
<Kbd>Enter</Kbd>
<Kbd>Esc</Kbd>
<Kbd>Tab</Kbd>
```

<div style="display: flex; gap: 0.5rem; align-items: center;">
  <Kbd>Enter</Kbd>
  <Kbd>Esc</Kbd>
  <Kbd>Tab</Kbd>
</div>

---

### Key combination

Wrap each key separately and place `+` between them in prose.

```astro
<Kbd>⌘</Kbd> + <Kbd>K</Kbd>
```

<Kbd>⌘</Kbd> + <Kbd>K</Kbd>

---

### Inline with text

```astro
Press <Kbd>Ctrl</Kbd> + <Kbd>S</Kbd> to save.
```

Press <Kbd>Ctrl</Kbd> + <Kbd>S</Kbd> to save.

---

### Icon keys

Use `icon` to render a symbol key (arrow keys, special symbols).

```astro
<Kbd icon="arrow-up" />
<Kbd icon="arrow-down" />
<Kbd icon="command" />
```

---

## Props API

| Prop | Type | Default | Description |
|---|---|---|---|
| `size` | `TextSize` | `"xs"` | Font size scale step. |
| `fam` | `Family` | `"mono"` | Font family. |
| `icon` | `SvgName` | `undefined` | Icon rendered inside the key cap instead of (or alongside) slot content. |

Inherits all remaining `TypographyProps` (`color`, `weight`, `align`, etc.) and `BaseComponentProps`.
