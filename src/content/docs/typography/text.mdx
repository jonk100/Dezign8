## Overview

`Text` is the go-to component for body copy, captions, labels, inline spans, and any other text that isn't a heading or keyboard key. It renders as `<p>` by default; change the element via `as`. All typography tokens are available as props.

---

## Usage

### Basic

```astro
<Text>Standard paragraph.</Text>
```

<Text>Standard paragraph.</Text>

---

### Tag

```astro
<Text as="span">Inline</Text>
<Text as="figcaption">Caption below an image</Text>
<Text as="strong">Bold semantic emphasis</Text>
<Text as="address">123 Main St</Text>
```

Valid tags: `p`, `span`, `div`, `li`, `strong`, `em`, `del`, `ins`, `mark`, `small`, `figcaption`, `cite`, `legend`, `dt`, `dd`, `address`.

---

### Size and weight

```astro
<Text size="sm" weight="normal">Small normal</Text>
<Text size="md" weight="medium">Medium medium</Text>

<Text size="2xl" weight="bold">2xl bold</Text>
```

---

### Truncation

```astro
<!-- Single line -->
<Text truncate>A very long line that will be clipped with an ellipsis…</Text>

<!-- Multi-line clamp -->
<Text clamp={3}>
  Three lines max. After that, an ellipsis is shown. Great for card
  descriptions or article previews where vertical space is limited.
</Text>
```

---

### Alignment and transforms

```astro
<Text align="center">Centered</Text>
<Text transform="uppercase" tracking="wide">Uppercase tracked</Text>
<Text fontStyle="italic">Italic</Text>
```

### Icon

## Props API

| Prop | Type | Default | Description |
|---|---|---|---|
| `as` | `TextTag` | `"p"` | HTML element to render. |
| `size` | `TextSize` | CSS default | Responsive font-size scale (`2xs`–`4xl`). |
| `weight` | `Weight` | CSS default | `thin`, `light`, `normal`, `medium`, `semibold`, `bold`, `black`. |
| `color` | `TextColor` | CSS default | Text color token. |
| `align` | `Align` | CSS default | `start`, `center`, `end`. |
| `leading` | `Leading` | CSS default | Line height: `none`, `tight`, `snug`, `normal`, `relaxed`, `loose`. |
| `tracking` | `Tracking` | CSS default | Letter spacing: `tight`, `normal`, `wide`, `wider`, `caps`. |
| `fam` | `Family` | CSS default | Font family: `sans`, `serif`, `mono`. |
| `transform` | `TypeTransform` | CSS default | `uppercase`, `lowercase`, `capitalize`. |
| `wrap` | `TypeWrap` | CSS default | Text wrapping behavior. |
| `decoration` | `TypeDecoration` | CSS default | `underline`, `line-through`. |
| `fontStyle` | `TypeStyle` | CSS default | `italic`, `oblique`. |
| `clamp` | `number` | `undefined` | Limit text to N lines with ellipsis. |
| `truncate` | `boolean` | `false` | Single-line clip with ellipsis. |
| `icon` | `SvgName` | `undefined` | Leading icon rendered before the slot. |

All `BaseComponentProps` are also accepted (`class`, `style`, `id`, spacing props, etc.).
