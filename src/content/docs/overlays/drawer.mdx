## Overview

`Drawer` is a panel that slides in from any edge of the viewport — end (right), start (left), top, or bottom. It uses the native `<dialog showModal()>` element for built-in focus trapping, backdrop, and Escape-key dismissal. Open it with `data-drawer-open` on any button, or imperatively via the `drawer` controller.

Defaults: `placement="end"`, `size="md"`, `closeOnBackdrop={true}`, `closeOnEsc={true}`.

## Usage

### Basic

```astro
---

---

</Drawer>
```

## Footer slot

Provide action buttons in the `footer` slot for confirm/cancel patterns.

```astro
<Drawer id="drawer-footer" title="Confirm action">
  <p>Are you sure you want to proceed?</p>
  <Button slot="footer" data-drawer-close="drawer-footer">Cancel</Button>
  <Button slot="footer" variant="solid" color="primary">Confirm</Button>
</Drawer>
```

## Programmatic API

```ts
import { drawer } from "@/design/overlays/components/drawer/drawer.client";

drawer.open("my-drawer");
drawer.close("my-drawer");
```

Custom events are dispatched on `window` when a drawer opens or closes:

```ts
window.addEventListener("drawer:open",  (e) => console.log(e.detail.id));
window.addEventListener("drawer:close", (e) => console.log(e.detail.id));
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `id` | `string` | — | **Required.** Used to wire triggers and the close button. |
| `title` | `string` | `undefined` | Optional heading in the drawer header. |
| `placement` | `DrawerPlacement` | `"end"` | Which edge to slide in from. |
| `size` | `DrawerSize` | `"md"` | Cross-axis panel size (width for side, height for top/bottom). |
| `closeOnBackdrop` | `boolean` | `true` | Close when clicking the backdrop. |
| `closeOnEsc` | `boolean` | `true` | Close on Escape key press. |

All `BaseComponentProps` are accepted (`class`, `style`, `id`, etc.).

## Slots

| Slot | Description |
|---|---|
| default | Main body content. |
| `footer` | Action row rendered at the bottom (confirm/cancel buttons). |

## Declarative triggers

| Attribute | Value | Behaviour |
|---|---|---|
| `data-drawer-open` | drawer `id` | Opens the named drawer on click. |
| `data-drawer-close` | drawer `id` | Closes the named drawer on click (auto-wired inside the drawer). |

---

## Accessibility

- Native `<dialog>` provides automatic focus trapping while open.
- Focus returns to the trigger element on close.
- Backdrop click and Escape dismissal are configurable via `closeOnBackdrop` / `closeOnEsc`.
- The close button has `aria-label="Close"`.
- When `title` is set, `aria-labelledby` links the dialog to the heading.
