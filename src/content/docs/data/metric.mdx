## Overview

The `Metric` component is designed for rich data display. It can present a value, a label, a prose description, and a trend indicator (up, down, or neutral). It works well inside card layouts on dashboards.

```astro
import Metric from "~/data/components/metric/Metric.astro";

<Metric 
  value="84%" 
  label="Engagement" 
  description="3/4 people agree with this longer thing." 
  trend="12%" 
  trendDirection="up" 
  variant="elevated" 
/>
```

### Loading State

When `loading` is set, `Metric` displays skeleton placeholders for its content.

<div class="not-content">
  <Metric loading variant="outlined" />
</div>

```astro
<Metric loading variant="outlined" />
```

### Custom Icons via Slots

You can pass an icon using the `icon` slot.

<div class="not-content">
  <Metric value="99.9%" label="Uptime" variant="soft">
    <svg slot="icon" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><path d="M12 2L2 7l10 5 10-5-10-5zM2 17l10 5 10-5M2 12l10 5 10-5"/></svg>
  </Metric>
</div>

```astro
<Metric value="99.9%" label="Uptime" variant="soft">
  <svg slot="icon" ... />
</Metric>
```


### Icon Integration

This component supports the **Hybrid Icon Composition** architecture. You can easily add an icon by passing the `icon` prop, or use the `<Icon>` component inside slots for more advanced layouts.

```astro
<!-- Basic prop usage -->
<Metric icon="star">Content</Metric>

<!-- Advanced slot usage -->
<Metric>
  Content <Icon name="chevron-right" />
</Metric>
```

For more details, see the [Icon component documentation](/assets/icon).
