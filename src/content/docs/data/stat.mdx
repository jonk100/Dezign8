## Overview

`Stat` highlights one number — a count, percentage, or measurement — alongside a brief label. Use it on dashboards, summary panels, or anywhere a single figure needs to stand out.

---

## Usage

### Basic

```astro
<Stat value="24k" label="Total users" />
<Stat value="98.5%" label="Uptime" />
```

### Slots

Use slots for complex value or label content.

```astro
<Stat>
  <span slot="value" style="color: var(--primary--base);">1,024</span>
  <span slot="label">Active sessions <small>(last 24h)</small></span>
</Stat>
```

## Props API

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` | `string \| number` | `undefined` | The primary value to display. Also available as a slot. |
| `label` | `string` | `undefined` | Descriptive label beneath the value. Also available as a slot. |
| `icon` | `SvgName` | `undefined` | Icon rendered alongside the value. |
| `variant` | `"plain" \| "outlined" \| "soft" \| "elevated"` | `"plain"` | Container decoration. |
| `color` | `ColorRole` | `undefined` | Accent color role applied to the value text. |
| `bg` | `ColorRole` | `undefined` | Background tint color role. |
| `loading` | `boolean` | `false` | Shows skeleton placeholder. |
| `caption` | `string` | `undefined` | Accessible label for screen readers when no visible heading precedes the stat. |

All `BaseComponentProps` are also accepted.

## Slots

| Slot | Description |
|---|---|
| `value` | Primary figure. Replaces the `value` prop when used. |
| `label` | Descriptive label. Replaces the `label` prop when used. |
