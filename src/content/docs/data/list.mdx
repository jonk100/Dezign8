## Overview

`List` is a primary component for displaying collections of items. It supports two rendering modes — data-driven for simplicity and compound for full structural control — and inherits all data category props: color channels, density, variants, and behavioral states.

## Usage & Examples

### Basic data-driven

Pass `data` and `itemFields` to let List handle rendering. `itemFields` maps keys from your data objects to the primary and secondary text lines in each list item.

```astro
<List
  data={users}
  itemFields={{ primary: "name", secondary: "role" }}
/>
```
<div style="border: 1px solid var(--border--default); padding: 1rem; border-radius: var(--radius--md); margin-bottom: 1rem;">
  <List data={users} itemFields={itemFields} />
</div>

### Ordered List

Pass `ordered` to render an `<ol>` instead of the default `<ul>`.

```astro

/>
```

### Selectable items

Checkboxes are rendered automatically. Wire selection state via `list:selectionchange` event on the wrapper.

```astro
<List data={users} itemFields={itemFields} color="primary" selectable />
```
<div style="border: 1px solid var(--border--default); padding: 1rem; border-radius: var(--radius--md); margin-bottom: 1rem;">
  <List data={users} itemFields={itemFields} color="primary" selectable />
</div>

```js
// Listen for selection changes on the wrapper element
document.querySelector('[data-selectable]')
  .addEventListener('list:selectionchange', e => {
    const { selected, all, none } = e.detail;
    // selected → number[] of selected row indices
    const selectedItems = selected.map(i => users[i]);
  });
```

## Props API

### List Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `data` | `ItemData[]` | — | Item records. Omit for compound mode. |
| `itemFields` | `{ primary: string, secondary?: string }` | — | Key mapping for data-driven mode. |
| `ordered` | `boolean` | `false` | Renders an `<ol>` instead of a `<ul>`. |

### Inherited Data Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `color` | `ColorRole` | — | Primary accent: borders, hover bg, selection indicators. |
| `bg` | `ColorRole` | — | Background tint: container fill, striped items. |
| `highlight` | `ColorRole` | — | Highlighted item accent (left border + subtle bg). |
| `variant` | `"plain" \| "outlined" \| "soft" \| "elevated"` | `"plain"` | Container decoration. |
| `size` | `"compact" \| "comfortable" \| "spacious"` | — | Item density. Scales padding proportionally. |
| `caption` | `string` | — | Semantic `<caption>` element for accessibility. |
| `loading` | `boolean` | — | Shows skeleton shimmer. Replaces list content with placeholder items. |
| `empty` | `boolean \| string` | — | Empty state. String overrides default message. Use `empty` slot for rich content. |
| `striped` | `boolean` | — | Alternating even-item background tint. |
| `bordered` | `boolean` | — | Borders between all items. |
| `interactive` | `boolean` | — | Hover bg + pointer cursor on list items. |
| `selectable` | `boolean` | — | Renders a checkbox on each item. Fires `list:selectionchange` on the wrapper. |
| `scrollable` | `boolean` | — | Enables vertical scroll (`overflow-y: auto`) on the wrapper. |

### ListItem Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `highlighted` | `boolean` | `false` | Applies the `--data--highlight--*` color channels for emphasis. |
| `href` | `string` | — | Renders the list item as an `<a>` tag. |

### Slots (List)

| Slot | Replaces | Notes |
|---|---|---|
| `default` | Data-driven `<li>`s | Use for compound mode with `<ListItem>` children. |
| `empty` | Default empty message | Any content; shown when `data.length === 0`. |

### Slots (ListItem)

| Slot | Description |
|---|---|
| `start` | Content at the start of the item (e.g., Avatar, Icon). |
| `default` | Main content area, typically for text. |
| `end` | Content at the end of the item (e.g., Badge, Button, timestamp). |

### `list:selectionchange` event

Fired on the wrapper `<div>` when any checkbox changes state.

```ts
event.detail: {
  selected: number[];  // 0-based indices of selected items
  all:  boolean;       // true when every item is selected
  none: boolean;       // true when no items are selected
}
```

## Design Decisions

**Wrapper div for scrollability.** `overflow: auto` on `<ul>` or `<ol>` can have inconsistent behavior. The wrapper `<div>` carries the `.data` class and all category-level styles; CSS vars cascade down into the list naturally.

**Selection state is always consumer-managed.** The component renders selection UI from the `selectable` prop but never reads or stores state itself. It emits the `list:selectionchange` event, and the consumer stores the state.

**Data-driven mode is for simple cases.** The `itemFields` prop handles the common use case of a primary and secondary line of text. For anything more complex (custom icons per item, complex action buttons), use compound mode with `<ListItem>` and its slots for full control.

**`_highlighted` key in data-driven mode.** Adding `_highlighted: true` to an item record in your `data` array marks that item with `data-highlighted`, which `list.css` styles using the `--data--highlight--*` channels. In compound mode, pass the `highlighted` prop to `<ListItem>` directly.
