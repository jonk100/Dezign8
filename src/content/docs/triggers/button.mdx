## Overview

`Button` is the primary interactive element. It renders as `<button>` by default and automatically switches to `<a>` when an `href` is provided. All visual tokens (`variant`, `color`, `radius`) are shared with the trigger system.

Defaults: `size="md"`, `variant="solid"`, `color="primary"`, `radius="md"`, `type="button"`.

### As link

Provide `href` to render as `<a>` with button styling. `target="_blank"` automatically injects `rel="noopener noreferrer"`.


## Button Group

`ButtonGroup` groups related buttons with shared borders, consistent sizing, and cohesive motions. It supports different layouts, states, and accessibility semantics via the `for` prop.

### Basic Grouping

```astro
<ButtonGroup for="semantic">
  <Button>One</Button>
  <Button>Two</Button>
  <Button>Three</Button>
</ButtonGroup>
```

<div style="margin-block-end: 1.5rem;">
  <ButtonGroup for="semantic">
    <Button>One</Button>
    <Button>Two</Button>
    <Button>Three</Button>
  </ButtonGroup>
</div>

---

### Size and Color Cascades

Properties set on the parent `ButtonGroup` automatically cascade to the children. Standalone buttons inside inherit the group's properties, while child buttons with explicit props override the cascade.

```astro
<ButtonGroup for="semantic" size="sm" variant="outlined" color="success">
  <Button>Accept</Button>
  <Button>Verify</Button>
  <Button color="neutral">Skip</Button> {/* explicit child override */}
</ButtonGroup>
```

<div style="margin-block-end: 1.5rem;">
  <ButtonGroup for="semantic" size="sm" variant="outlined" color="success">
    <Button>Accept</Button>
    <Button>Verify</Button>
    <Button color="neutral">Skip</Button>
  </ButtonGroup>
</div>

### Segmented Control

Use `for="control"` for segmented controls. It manages active selection state like a radio group (only one button active at a time) and supports full keyboard arrow key navigation. Pass `name` and `value` to support form submissions.

```astro
<ButtonGroup for="control" name="player" value="play">
  <Button value="play" icon="play" iconOnly aria-label="Play" />
  <Button value="pause" icon="pause" iconOnly aria-label="Pause" />
  <Button value="stop" icon="stop" iconOnly aria-label="Stop" />
</ButtonGroup>
```

    <Button value="pause" icon="pause" iconOnly aria-label="Pause" />

### Toolbar

Use `for="toolbar"` for edit-style toolbars. It implements WAI-ARIA toolbar keyboard navigation (only the active/last-focused item is focusable via Tab, and arrow keys shift focus).

```astro
  <Button icon="bold" iconOnly aria-label="Bold" variant="ghost" />
  <Button icon="italic" iconOnly aria-label="Italic" variant="ghost" />
  <Button icon="underline" iconOnly aria-label="Underline" variant="ghost" />
```

## Props API

### Button Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `variant` | `"solid" \| "outlined" \| "soft" \| "ghost" \| "dashed"` | `"solid"` | Visual treatment. |
| `color` | `ColorRole` | `"primary"` | Semantic color role. |
| `size` | `"2xs"…"2xl"` | `"md"` | Spatial scale. |
| `radius` | `Radius` | `"md"` | Border radius. |
| `icon` | `SvgName` | `undefined` | Leading icon rendered before the slot. |
| `iconOnly` | `boolean` | `false` | Square aspect ratio, removes inline padding. Requires `aria-label`. |
| `fullWidth` | `boolean` | `false` | Expands to 100% container width. |
| `disabled` | `boolean` | `false` | Disables all interaction. |
| `loading` | `boolean` | `false` | Shows loading state. |
| `type` | `"button" \| "submit" \| "reset"` | `"button"` | HTML button type. |
| `href` | `string` | `undefined` | Renders as `<a>` when set. |
| `target` | `string` | `undefined` | Anchor target. |
| `rel` | `string` | `undefined` | Anchor rel. Auto-set to `"noopener noreferrer"` when `target="_blank"`. |

### ButtonGroup Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `for` | `"semantic" \| "control" \| "toolbar" \| "split" \| "toggle" \| "cluster"` | *Required* | Defines the layout behavior and accessibility role. |
| `grouped` | `boolean` | `true` | Collapses child borders and aligns border-radiuses. (Defaults to `false` for `for="cluster"` or with custom `grid`). |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Alignment of the button group. Automatically stacks vertically on narrow screens. |
| `grid` | `"22" \| "33" \| "44" \| "222" \| "131" \| "141" \| "212"` | `undefined` | Grid layout preset aligning child buttons into fixed rows. |
| `size` | `"2xs"…"2xl"` | `undefined` | Size step cascading to all child buttons. |
| `color` | `ColorRole` | `undefined` | Semantic color role cascading to all child buttons. |
| `variant` | `TriggerVariant` | `undefined` | Visual variant style cascading to all child buttons. |
| `radius` | `Radius` | `undefined` | Border radius cascading to all child buttons. |
| `value` | `string` | `undefined` | Initial active selection value. Only used when `for="control"`. |
| `values` | `string[]` | `undefined` | Initial active selection values. Only used when `for="toggle"`. |
| `name` | `string` | `undefined` | Form input name. Creates hidden inputs to participate in HTML form submission. Only used when `for="control"` or `for="toggle"`. |

All `BaseComponentProps` are also accepted (`class`, `style`, `id`, spacing props, etc.).

## Accessibility

- Use `iconOnly` buttons only with an explicit `aria-label` — the type system enforces this.
- `disabled` sets both the HTML attribute and `data-disabled` for CSS targeting.
- `loading` sets `data-loading` and should be paired with screen-reader text inside the slot if the label changes.
