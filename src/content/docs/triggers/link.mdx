## Overview

`Link` extends `TypographyProps`, so it inherits all text styling (size, weight, family, color) and blends naturally into surrounding prose. When `href` is omitted it renders as a placeholder anchor with no navigation. When `target="_blank"` or `external` is set, `rel="noopener noreferrer"` is applied automatically.

Default underline: `"hover"`.

---

## Usage

### Basic

```astro
<Link href="/about">About us</Link>
```

<Link href="/about">About us</Link>

---

### Underline

```astro
<Link href="#" underline="always">Always underlined</Link>
<Link href="#" underline="hover">Hover only (default)</Link>
<Link href="#" underline="never">Never underlined</Link>
```

### Typography tokens

Any typography prop passes straight through.

```astro
<Link href="/brand" size="xl" weight="bold" color="primary">Brand link</Link>
<Link href="/terms" size="sm" color="muted">Terms of service</Link>
```

  <Link href="/brand" size="xl" weight="bold" color="primary">Brand link</Link>
  <Link href="/terms" size="sm" color="muted">Terms of service</Link>
</div>

---

### External

`external` shorthand sets `target="_blank"` and `rel="noopener noreferrer"` together.

```astro
<Link href="https://example.com" external>External site</Link>
```

---

### Icon

```astro
<Link href="/docs" icon="book">Documentation</Link>
<Link href="https://github.com" external icon="github">GitHub</Link>
```

---

### Placeholder (no href)

Omit `href` for a styled, non-navigating anchor — useful during prototyping or when click is handled by a parent.

```astro
<Link>Click handler on parent</Link>
```

## Props API

| Prop | Type | Default | Description |
|---|---|---|---|
| `href` | `string` | `undefined` | Destination URL. Omit to render a placeholder. |
| `target` | `string` | `undefined` | Where to open the link. |
| `rel` | `string` | `undefined` | Link relationship. Auto-set to `"noopener noreferrer"` when `target="_blank"` or `external`. |
| `external` | `boolean` | `false` | Shorthand for `target="_blank"` + secure `rel`. |
| `underline` | `"always" \| "hover" \| "never"` | `"hover"` | When the underline is visible. |
| `icon` | `SvgName` | `undefined` | Leading icon rendered before the slot. |

Inherits all `TypographyProps` (`size`, `weight`, `family`, `color`, `align`, etc.) and `BaseComponentProps`.

---

## Accessibility

- Links without `href` have no navigation semantics — use only for composition with a JS click handler on a parent.
- `external` links open in a new tab; consider appending visually hidden text like `(opens in new tab)` for screen reader users in content-heavy contexts.
