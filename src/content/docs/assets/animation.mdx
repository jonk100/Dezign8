## Overview

Dezign8 includes a powerful, hardware-accelerated motion system out of the box. Every single component in the design system extends `BaseComponentProps`, which means **every component supports the `m` (motion) prop**. 

The API uses a clean, declarative syntax: `motion="{phase}:{name}/{duration}/{delay}"`

- **Phases**: `enter` (on mount), `idle` (infinite loops), `exit` (on dismiss)
- **Compound**: Chain multiple animations with commas (e.g. `shakeIn/300, fadeIn/200`)
- **Accessibility**: Automatically stripped if the user has `prefers-reduced-motion: reduce`

## 1. Enter Animations (Mount)

Enter animations trigger automatically when the element mounts in the DOM.

### Slides & Fades
Perfect for smooth, unobtrusive entrances.

```astro
<Alert color="info" motion="enter:slideLeft/400" mDistance="x4">
  Slide in from the left
</Alert>
<Alert color="success" motion="enter:slideDown/400">
  Slide in from the top
</Alert>
<Alert color="primary" motion="enter:fadeIn/600">
  Fade in gently
</Alert>
```

## 3. Exit Animations (Dismissible)

Because you cannot natively animate an element that is being instantly removed from the DOM, Dezign8 handles this via **Delegated Dismiss**. 
When a user clicks a button with the `data-dismiss` attribute, the system will read the `data-m-exit` attributes, play the animation, wait for it to finish, and *then* hide the element.

*Click the X on these banners/toasts to see their exit animations!*

```astro
<Banner color="primary" dismissible motion="exit:slideUp/300">
  This banner slides up and disappears when closed.
</Banner>

<Banner color="danger" dismissible motion="exit:shakeOut/400, fadeOut/400">
  This error banner shakes violently before fading out.
</Banner>

<Toast title="Action Complete" color="success" dismissible motion="exit:slideRight/300">
  This toast will slide off-screen to the right.
</Toast>
```

## 4. Scroll-Triggered Animations

By default, `enter` animations play immediately on mount. If an element is far down the page, it will animate off-screen before you scroll to it! 

You can fix this by adding the `scroll` keyword to your motion string. The element will remain hidden until you scroll it into view, and *then* the `enter` animation plays. It will also seamlessly repeat every time you scroll past it!

```astro
<Alert color="info" motion="scroll enter:slideLeft/600">
  I animate in every time you scroll down to me.
</Alert>
```

## 5. Compound & Timing Adjustments

You can chain multiple animations together in a single phase using commas, and you can tweak the `duration` and `delay` dynamically.
Syntax: `name/duration/delay` (duration and delay in milliseconds).

This is especially powerful when combined with `scroll` to create staggered entrances:

```astro
<div style="display: flex; gap: 1rem;">
  <Button motion="scroll enter:slideUp/400/0, fadeIn/400/0">First</Button>
  <Button motion="scroll enter:slideUp/400/200, fadeIn/400/200">Second</Button>
  <Button motion="scroll enter:slideUp/400/400, fadeIn/400/400">Third</Button>
</div>
```

## 6. Customizing Travel Distance

Animations that involve movement (like `slide` and `bounce`) use CSS variables for their translation distance. By default, slides move `1.5rem` and bounces move `2rem`. You can override this per element by setting `--m--dist` in the style attribute.

```astro
<div style="display: flex; gap: 1rem;">
  <Alert color="info" motion="scroll enter:slideUp/600">Default (1.5rem)</Alert>
  <Alert color="primary" style="--m--dist: 100px" motion="scroll enter:slideUp/600">Custom (100px)</Alert>
</div>
```

## Available Animations Reference

**Slides:** `slideUp`, `slideDown`, `slideLeft`, `slideRight`  
**Fades:** `fadeIn`, `fadeOut`  
**Stretches:** `stretchUp`, `stretchDown`, `stretchLeft`, `stretchRight`  
**Spins:** `spinIn`, `spinOut`, `spinUp`, `spinDown`, `spinLeft`, `spinRight`  
**Shakes:** `shakeIn`, `shakeOut`, `shakeInfinite`, `shakeOnOff`, `shakeInPlace`  
**Blinks:** `blinkIn`, `blinkOut`, `blinkUp`, `blinkDown`, `blinkLeft`, `blinkRight`  
**Bounces:** `bounceUp`, `bounceDown`, `bounceLeft`, `bounceRight`, `bounceInPlace`  
**Scaling:** `appear`, `disappear`
