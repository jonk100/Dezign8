## Overview

`Panel` provides a structural surface layer for collapsible regions, sidebars, or drawers. It inherits all surface properties and uses `layer="1"` by default for a slight elevation off the page background.

## Examples

### Basic Panel

<div style="margin-bottom: 2rem;">
  <Panel padding="md" radius="md" variant="outlined">
    <h4 style="margin-top: 0; margin-bottom: 0.5rem;">Configuration Options</h4>
    <p style="margin: 0; color: var(--text--secondary);">A panel provides a grouped surface for related content.</p>
  </Panel>
</div>

```astro
<Panel padding="md" radius="md" variant="outlined">
  <h4>Configuration Options</h4>
  <p>A panel provides a grouped surface for related content.</p>
</Panel>
```

### The `as` Prop

For semantic HTML, panels can easily be rendered as an `<aside>`, `<section>`, or `<details>` element using the `as` prop.

```astro
<Panel as="aside" padding="lg" variant="soft">
  <nav>
    <!-- Sidebar navigation content -->
  </nav>
</Panel>
```

### Variants and Elevation

Panels inherit surface variants (`plain`, `outlined`, `soft`, `elevated`, `glass`) and `layer` props.

<div style="display: flex; gap: 1rem; margin-bottom: 2rem; flex-wrap: wrap;">
  <Panel variant="soft" padding="md" style="width: 200px;">
    <h4 style="margin-top: 0;">Soft Panel</h4>
    <p style="margin: 0; color: var(--text--secondary); font-size: 0.875rem;">Uses variant="soft"</p>
  </Panel>
  
  <Panel layer="2" variant="elevated" padding="md" style="width: 200px;">
    <h4 style="margin-top: 0;">Elevated Panel</h4>
    <p style="margin: 0; color: var(--text--secondary); font-size: 0.875rem;">Uses layer="2"</p>
  </Panel>
</div>

```astro
<Panel variant="soft" padding="md">
  <h4>Soft Panel</h4>
  <p>Uses variant="soft"</p>
</Panel>

<Panel layer="2" variant="elevated" padding="md">
  <h4>Elevated Panel</h4>
  <p>Uses layer="2"</p>
</Panel>
```
