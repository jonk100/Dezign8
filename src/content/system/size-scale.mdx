# Unified Size Scale

In this design system, the `size` prop acts as an **orchestrator** for all the individual CSS properties that define a component's physical appearance and dimensions. 

Rather than adjusting a single isolated property, changing the `size` prop coordinates multiple properties at once to maintain correct visual balance.

For example, when you set `<Button size="md">`, the `size` prop coordinates:
* **Height** (e.g., standardizing control heights)
* **Padding** (inline and block spacing)
* **Gap** (spacing between icons and text)
* **Font Size** (matching text hierarchy to container scale)

---

## Mapping to CSS Custom Properties

Under the hood, component hooks map the `size` prop to component-scoped CSS custom properties (variables). This keeps layout values decoupled from component templates:

```css
/* Emitted inline on a <button size="md"> element: */
--button--h: var(--ui-height--md);
--button--p: var(--space-in--md);
--button--pi: var(--space-in--md);
--button--gap: var(--space-in--xs);
--button--fs: var(--fsf--sm);
```

Component stylesheets (e.g., `button.css`) consume these variables, ensuring spacing and alignment are completely consistent:
```css
.button {
  min-height:     var(--button--h);
  padding-block:  var(--button--p);
  padding-inline: var(--button--pi);
  font-size:      var(--button--fs);
}
```

---

## The 12-Step Shared Scale

The design system standardizes the names of all size scales under a single, unified 12-step scale:

```
3xs  →  2xs  →  xs  →  sm  →  md  →  lg  →  xl  →  2xl  →  3xl  →  4xl  →  5xl  →  6xl
```

By sharing the same step names across all domains, we minimize cognitive load for developers while maintaining the flexibility to tune actual physical values independently (e.g., `md` spacing can map to `16px` while `md` font-size maps to `14px`).

---

## Fluid vs. Fixed Font Scales

Typography size changes behave differently depending on the context:

1. **Fluid Font Sizes (`fs--*`)**: Used for page copy, layout headings, and article text. These sizes map to CSS `clamp()` functions that grow dynamically based on the viewport width.
2. **Fixed Font Sizes (`fsf--*` or `label--*`)**: Used for text inside structured UI controls (like buttons, badges, input tags, and helper texts). These map to static `rem`/`px` values so that structural components remain stable regardless of viewport scaling.

---

## Centralized Sizing Resolution (`resolveComponentSizes`)

To prevent components from writing custom resolver functions and duplicating assertions, size mappings are fully declarative and resolved using the shared helper in `src/design/shared/base.tokens.ts`:

```ts
import { resolveComponentSizes } from "~/shared/base.tokens";
import { BUTTON_SIZE_MAP } from "./button.tokens";

// In button.hook.ts:
const sizeStyle = resolveComponentSizes("button", size, BUTTON_SIZE_MAP);
```
